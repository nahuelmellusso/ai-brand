## What this repo is

A fork of `@openedx/brand-openedx` — the branding/theming package consumed by Open edX microfrontends (MFEs). It supplies logos, fonts, and a Paragon-compatible CSS theme. The published `dist/` artifacts are what MFEs actually import.

## Commands

```bash
npm install          # install deps (Paragon CLI + nodemon)
make build           # full build: clean → tokens → scss → copy assets to dist/
make build-tokens    # compile JSON design tokens → paragon/build/
make build-scss      # compile SCSS → dist/core.css + dist/light.css
make clean           # remove dist/ and paragon/build/
npm run build:watch  # watch mode (rebuilds on any non-dist change)
```

No test suite exists in this package.

## Architecture

### Build pipeline

1. **`make build-tokens`** — `paragon build-tokens` reads JSON token files from `paragon/tokens/` (Style Dictionary format) and writes generated CSS/SCSS into `paragon/build/`.
2. **`make build-scss`** — `paragon build-scss` compiles `paragon/core.scss` (core bundle) and `paragon/build/themes/` (theme bundles) into `dist/core.css` and `dist/light.css` (plus minified variants and source maps).
3. **`make build`** additionally copies `paragon/fonts/`, `paragon/images/`, and root SVG/PNG/ICO assets into `dist/`.

### Token customization (canonical method for Paragon 23)

All theme customization should go through JSON design tokens, not SCSS:

- `paragon/tokens/core/global/colors.json` — global color palette overrides
- `paragon/tokens/core/global/typography.json` — font family, sizes, weights
- `paragon/tokens/themes/light/colors.json` — light-theme-specific color overrides

Token values follow [Style Dictionary](https://styledictionary.com/) format (`$value`, `$type`).

### SCSS files

- `paragon/core.scss` — entry point assembled by `paragon build-scss`. Use for non-tokenizable additions (custom `@media`, brand-specific selectors). Font `@imports` go in `_fonts.scss`, not here.
- `paragon/_fonts.scss` — `@font-face` declarations for GT Walsheim (self-hosted woff files in `paragon/fonts/`) and Google Fonts imports (Inter, Roboto Mono).
- `paragon/_variables.scss` — legacy SCSS variable stubs (`$primary`, `$secondary`, etc.). These are not the canonical customization path with Paragon 23.
- `paragon/_overrides.scss` — CSS custom property overrides scoped to `[data-theme="light"]`. Supplements token output for values not covered by the token pipeline.

### Brand identity

- Primary color: `#505fb4` (blue-purple)
- Secondary color: `#7a99fc`
- Primary font: GT Walsheim (self-hosted), with Inter as the Google Fonts fallback

### Required dist assets

Consuming MFEs expect these specific filenames:
- `dist/logo.svg`, `dist/logo-trademark.svg`, `dist/logo-white.svg`, `dist/favicon.ico`
- `dist/core.css` / `dist/core.min.css`
- `dist/light.css` / `dist/light.min.css`
- `dist/theme-urls.json` (generated by the build, maps theme names to CSS URLs)
- `dist/images/card-imagecap-fallback.png`
